* Bugs

** BUG-1: =report= alias not discoverable in --help

=ccx --help= lists =insight= but not =report=. If =report= is meant
to be a user-facing alias, cobra needs explicit alias registration:

#+begin_src go
Aliases: []string{"report"},
#+end_src

Severity: cosmetic / discoverability.

** BUG-2: --since/--until blocked by --scope default

=internal/cmd/log.go:130= guards with =logScope != ""=, but =--scope=
defaults to ="today"= (set in =insight.go:46=), so the condition is
always true. Using =--since= or =--until= without explicitly clearing
scope errors with:

: ccx: --scope cannot be combined with --since or --until

Fix: replace =logScope != ""= with =cmd.Flags().Changed("scope")= so
cobra distinguishes explicit user intent from the default value.

Workaround: =--scope "" --since 2026-05-20 --until 2026-05-25= works.

Severity: functional — blocks the documented =--since/--until= flow.
