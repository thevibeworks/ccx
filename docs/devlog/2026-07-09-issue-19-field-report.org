** Context
Issue #19 grilled ccx from real usage: a 60-turn / $177 / 35-day
session recapped through the shipped skills, driven skeptically,
five receipts filed plus an architecture comment. The bugs were
individually small; the pattern underneath them was not.

** Why
Three of the five receipts share one root: the skills version with
the repo, the binary versions with tags, and nothing enforces
agreement. The other two (wall-span duration, silent local time) are
honesty bugs in numbers the skills tell agents to trust ("numbers
come from the trace, never estimated" — so the trace must not lie).

** What
- =FEAT= ~ccx skills~ command: skills embedded via go:embed;
  ~install [--scope user|project]~ + ~list~ with drift detection.
  install.sh skill step now delegates to the binary.
- =FEAT= ~active_seconds~ per turn and in stats: sum of
  inter-message gaps, each capped at 5 min. Outline header and turn
  badges use it; wall-span stays in ~duration_seconds~.
- =FIX= Session ID lookup widens workspace miss to all projects
  (IDs are globally unique); explicit ~-p~ scope errors name the
  project searched and suggest ~--all~.
- =FIX= Outline header states rendered timezone (~times UTC-7~).
- =CHANGE= docs/schema.md: kinds table, versioning policy, semantics.
- =CHANGE= recap/retro land durable knowledge with
  ~[ccx:<session-id> #turn.step]~ citations; explicit cross-routing
  in descriptions; minimum-version preflight.

** How
- Embed lives in ~skills/embed.go~ (package skills, ~//go:embed
  */SKILL.md~) — the Go file sits next to the data it embeds.
  ~TestBundledSkillsMatchRepoFiles~ pins embedded == repo bytes.
- Fallback lives in ~resolveSessionInQuery~ (shared by
  trace/view/export) so all three commands widen consistently.
  ~@N~ index lookups stay scope-relative — an index is only
  meaningful within the scope that ordered it.
- Active time: cap semantics (~min(gap, 5m)~ summed) over skip
  semantics — a sparse-but-real work pattern (events every 8 min)
  still counts, while an overnight gap adds at most one cap.
